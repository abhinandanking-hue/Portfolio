# Abhinandan Nidoni — Portfolio

A personal portfolio for Abhinandan Nidoni, built with static HTML, CSS, and JavaScript. No build step or package installation is required.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server. For example, if Python 3 is installed:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

Portfolio images are stored in the local `assets/` folder.
